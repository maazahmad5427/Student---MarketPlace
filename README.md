# CampusLoop — Online Student Marketplace

CampusLoop is a responsive student-to-student marketplace prototype styled with the Oceanic Luxe palette: Oceanic Blue #2D415A, Warm Clay #C56F4E, Warm Sand #F1E5DA and Soft Ivory #FBF7F2.

## Run
Open index.html in a modern browser. No build step is required. The demo stores its records in browser Local Storage.

## Included prototype workflows
- Public marketplace landing page and listing discovery.
- Category filters and text search.
- Student account sign-in and registration.
- Student listings, profile details, buying requests and seller approval queue.
- Seller approve/decline decisions and completion of approved exchanges.
- Administrator listing moderation.
- Saved items and profile-specific listing/request metrics.
- Responsive layouts for desktop and mobile.

## Prototype boundary
This is a front-end demonstration, not a production service. Local Storage is per browser/device, demo passwords are not securely stored, and client-side role checks are not a security boundary. Production use requires a backend, database, password hashing, institutional email verification, server-side authorization, secure sessions, privacy controls and backups. Payment and physical exchange are arranged by students outside the application.
