# 25-Minute Presentation Outline

1. Project overview and campus problem — 2 minutes.
2. Assignment 4 SRS scope, actors and requirements baseline — 3 minutes.
3. Architecture and component/sequence diagrams — 3 minutes.
4. Figma style guide, responsive screens and prototype walkthrough — 4 minutes.
5. Live website demonstration: search, listing, sign-in and reservation demo — 6 minutes.
6. Testing strategy, test cases and honest execution results — 3 minutes.
7. Deployment, limitations and conclusion — 2 minutes.
8. Questions — 2 minutes.

Before presenting, execute the test plan on the deployed build, record actual outcomes, and replace any demo-only wording that no longer describes the implementation.
